# Projeto - PDI (IFNMG)

Este repositório contém atividades e implementações desenvolvidas para a disciplina de **PDI (Processamento Digital de Imagens)** do **Instituto Federal do Norte de Minas Gerais (IFNMG)**.

O objetivo deste repositório é armazenar códigos, experimentos e estudos realizados durante a disciplina, aplicando conceitos fundamentais de processamento de imagens.

## Conteúdo
- Implementações de algoritmos de processamento de imagens
- Experimentos realizados nas aulas
- Testes e análises de resultados
